# 📊 Loan Portfolio Risk Simulation & Analysis  

This project simulates a **consumer loan portfolio** and applies **risk analytics and machine learning** to study loan performance, pricing, and default risk. It demonstrates the use of **Python, data visualization, and predictive modeling** in financial risk management.  

---

## 🚀 Project Overview  
- **Synthetic Dataset Generator**: Created 2,000+ consumer loans with realistic features (loan amount, interest rate, FICO score, income, DTI, loan grade).  
- **Exploratory Data Analysis (EDA)**:  
  - Loan distribution by grade, channel, and vintage.  
  - Risk-based pricing patterns.  
  - Portfolio-level performance metrics (default rate, average FICO, total volume).  
- **Machine Learning Model**:  
  - Trained a **Random Forest** to predict loan default risk.  
  - Evaluated model accuracy and feature importance.  
- **Risk Insights & Visualization**:  
  - Default trends across vintages.  
  - Channel-level risk and profitability analysis.  
  - Pricing vs. risk elasticity curves.  

---
## 🛠️ Tech Stack  
- **Languages**: Python  
- **Libraries**: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn  

---

## 📈 Key Results  
- Simulated a $29M loan portfolio with a **22.5% default rate**.  
- Demonstrated **risk-based pricing strategies** and their impact on loan profitability.  
- Built a **default prediction model** with strong performance (Random Forest).  
- Visualized how borrower attributes (FICO, DTI, income) drive default risk.
